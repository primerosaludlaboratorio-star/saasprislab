# Fuentes documentales Wondfo Finecare FS113

## Documento incorporado

- `restringido/SOP for Lis connection Plus Español.pptx`: procedimiento de conexión LIS del Finecare FIA Meter Plus FS113, 16 diapositivas.

## Alcance

La presentación documenta la conexión Ethernet entre el medidor y la PC, la configuración de red del equipo, el software `ReceiveFormTemp`, la recuperación manual desde historial y el envío automático de resultados al servidor LIS.

## Seguridad

El archivo original contiene parámetros de red y una credencial de configuración del equipo. Por ese motivo se conserva en la carpeta `restringido/` y no se deben copiar esos valores a documentación pública, código, repositorios públicos ni tickets. Antes de compartirlo externamente debe generarse una copia redactada y, de ser posible, cambiar la credencial predeterminada del equipo.

## Validación pendiente

Antes de implementar la interfase Wondfo-PRISLAB se debe confirmar la IP vigente, puerto LIS, formato de mensajes, equipo destino y prueba real de recepción sin alterar la configuración productiva.
