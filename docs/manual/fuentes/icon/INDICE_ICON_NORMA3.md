# Fuentes documentales Icon / Norma-3

## Documentos incorporados

- `Norma Icon Manual de usuario 1.3b8.pdf` — manual del operador del analizador hematológico automatizado de 3 partes Icon, versión de software 0.2.533.0, revisión 1.3b8, 113 páginas.
- `PROTOCOLO INTERFASE NORMA-3.pdf` — protocolo de conectividad HL7 del Icon/Norma-3, revisión documentada hasta la versión bidireccional de 2019, 10 páginas.

## Uso previsto

Estas fuentes se utilizarán para documentar operación, mantenimiento, capacitación, mensajes HL7, lotes de reactivo, rangos, banderas, resultados y errores de interfase del Icon.

No se activará una interfase ni se modificarán reglas de resultados hasta validar el protocolo contra la configuración vigente del equipo y el catálogo humano de PRISLAB.
